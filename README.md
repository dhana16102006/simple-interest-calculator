
# Simple Interest Calculator

## About the Project
The Simple Interest Calculator is a Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual interest rate (percentage)
- Time period (in years)

## Output
- Calculated simple interest
- Total amount (principal + interest)

## Example
Principal: 10000
Rate: 5
Time: 2 years

Simple Interest = (10000 × 5 × 2) / 100 = 1000

Total Amount = 10000 + 1000 = 11000

## Requirements
- Bash shell
- Linux, macOS, or Windows with Git Bash

## How to Run
```bash
bash simple-interest.sh
```
